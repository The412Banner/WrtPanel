First test build of WrtPanel, an Android app that manages OpenWrt routers through LuCI.

**What it does**
- Signs in like the LuCI web interface and shows the router's own menu as native pages: Status (Overview, Routing, Firewall, System and Kernel Log, Processes, Channel Analysis, Realtime Graphs), System (System, Administration, Software, Startup, Scheduled Tasks, Mount Points, LED Configuration, Backup / Flash Firmware, Reboot), Services (Network Shares), Network (Interfaces, Wireless, Routing, DHCP, DNS, Diagnostics, Firewall).
- Save, Save & Apply (with the router's automatic rollback), Apply unchecked and Revert, using the same LuCI endpoints and timings as the web interface.
- LuCI apps (plugins) can be installed and removed under System › Software; their pages appear in the app's menu. Plugin pages without a native screen open inside the app, already signed in.
- Several routers can be saved; passwords are stored encrypted. HTTPS routers with self-signed certificates are supported (the certificate is pinned after you confirm it).
- Checks this repository's releases on start and once a day, shows a notification for a newer version and installs it through Android's package installer. Test builds like this one are offered when "Include test builds" is on in App settings.

**Tested**
- CI: unit tests, release build, testkey signature (v1, v2, v3).
- Emulator: every page of the menu against an OpenWrt 25.12.6 test router.
- Phone: login, Overview, Network Shares, Interfaces and Software on an OpenWrt 25.12.6 router (read-only); Save & Apply on a test router.

**Not tested yet**
- Package installs, firmware flashing, reboot and the rollback path on a real router; wireless pages with active radios; HTTPS routers.

**Install**
Download `WrtPanel-v0.1.0-pre1.apk` below. It is signed with the public AOSP test key, so later builds install over it.
