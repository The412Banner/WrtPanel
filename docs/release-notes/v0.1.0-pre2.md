Second test build of WrtPanel.

**Changes since v0.1.0-pre1**
- Side menu: every group can now be collapsed. The group of the page you are on was always forced open.
- Lists on phones (Processes, routes, leases and other tables) are more compact: the details of each entry wrap side by side instead of one per line.

**Install**
If you have v0.1.0-pre1 with "Include test builds" turned on, WrtPanel offers this update by itself (App settings → Check now to look right away). Otherwise download `WrtPanel-v0.1.0-pre2.apk` below; it installs over the previous version.
